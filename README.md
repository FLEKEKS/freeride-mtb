# Freeride MTB V61 — New Frames & Garage

V61 додає три окремі прозорі PNG-спрайти рам: Aggressive DH, Trail та Hardtail. Рами мають різну геометрію; Aggressive і Trail мають задню підвіску, Hardtail — жорсткий задній трикутник. Вибір рами та сумісність деталей збережені з V60.

Файли для GitHub Pages: index.html, manifest.json, sw.js, README.md. Завантажуйте їх у корінь репозиторію із заміною старих.
